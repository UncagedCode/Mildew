# Graham Performance & Broadcast Editing Rules

## Core principle

Graham must feel like a **real presenter being directed by a cheap live television production**, not a talking game avatar.

The low-budget solution is therefore not to keep him visible continuously. Use television grammar.

## Rule 1 — voice can continue while Graham is off-screen

Dynamic lines should routinely begin on Graham and continue over:

- scoreboards;
- question graphics;
- player podiums;
- contestant avatars;
- answer reveals;
- diagrams/images;
- fake archive inserts;
- sponsor cards;
- studio wide shots.

This is authentic television direction and hides limited lip-sync naturally.

## Rule 2 — avoid slideshow cuts between emotional stills

Never sequence:

`neutral -> angry -> smile`

with hard cuts while Graham occupies the same camera shot.

Instead use one of these:

### Cutaway bridge

1. Graham neutral.
2. Cut to player/graphic.
3. Audio event occurs.
4. Return to Graham irritated.

### Reaction motion bridge

Use an existing motion excerpt for the turn/recovery.

### Broadcast camera bridge

Cut Camera 1 -> Camera 2/wide -> different Graham state.

## Rule 3 — emotional transitions should be physically plausible

When visible:

- eyes move first;
- head follows;
- shoulders move less;
- expression decays rather than switches;
- irritation can remain beneath the recovered presenter smile.

## Rule 4 — broad smiles are punctuation

The broad presenter smile is for:

- opening;
- applause;
- winning reveal;
- over-the-top congratulations;
- deliberate forced cheerfulness.

Routine hosting should usually use `restrained_smile` or `recovered_presenter`.

## Rule 5 — analogue treatment is not a disguise for bad animation

Use:

- slight softness;
- chroma bleed;
- mild noise;
- subtle interlace treatment;
- occasional tracking errors.

Do not bury Graham beneath excessive glitching. The broadcast should remain legible and mostly ordinary.

## Rule 6 — the still system should move like a camera, not a cardboard cutout

Until transparent character cutouts exist, treat each full-frame still as a **camera plate**.

Acceptable motion:

- 0.2–0.7% slow push-in;
- 1–3 px frame drift;
- tiny simulated operator correction;
- brief exposure/color fluctuation;
- analogue wobble;
- cut timing variation.

Do **not** scale Graham's whole full-frame plate up/down rapidly to simulate breathing; that moves the set as well and looks wrong.

If later alpha-cutout Graham assets exist, independent torso breathing can be added then.

## Rule 7 — speaking stills are short bridges

The crude `speech_cycle` frames can create a low-resolution mouth impression for a second or so. They should not be the default for long monologues.

Recommended structure for a dynamic line:

1. 0.4–1.0 sec visible Graham speaking.
2. Cut to scoreboard/question/player.
3. Voice continues.
4. Return to reaction or reading-cards state.

## Rule 8 — use silence deliberately

For unsettling moments, the cheapest effect is often:

- static Graham state;
- audience ambience disappears;
- slight studio room tone remains;
- Graham looks off-camera;
- nothing happens for 0.5–2 seconds;
- broadcast resumes.

No expensive video is required.

## Rule 9 — increased motion realism can itself mark an incident

Most of Mildew may use still-driven Graham. A rare cut to one of the existing full-motion reaction excerpts can feel subtly different and therefore more unsettling.

Do not announce or explain the difference.

## Rule 10 — never turn Graham into analogue-horror iconography

Avoid:

- black eyes;
- stretched smiles;
- face warping;
- demonic frames;
- excessive VHS corruption;
- jumpscare poses.

Mildew is disturbing because Graham remains recognisably normal.
