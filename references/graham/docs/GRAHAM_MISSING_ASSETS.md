# Graham — Missing Asset Backlog

The current footage is sufficient for the first vertical slice, but it does not yet cover every long-term presenter state.

## Priority A — useful soon, but do not block Checkpoint 1

### 1. Subtle disappointment, front-facing
Desired expression:

- lips pressed or small downward expression;
- raised eyebrow optional;
- no theatrical sadness;
- cue cards in normal position.

Use for wrong answers and mild contempt.

### 2. Restrained amusement
A small laugh/smirk that does not become the large generic AI-presenter grin.

Use for:

- funny player answer;
- Graham enjoying a humiliation;
- audience joke.

### 3. Front-facing irritation
The existing irritation is side-facing. A direct-to-camera annoyed state would make transitions easier.

### 4. Look off-camera in the opposite direction
Existing strong reaction primarily looks one direction. Add the mirror-direction performance eventually so incidents are not visually repetitive.

### 5. Clean blink-compatible neutral
A near-identical pair of frames, eyes open / eyes closed, with body and background locked. This is preferable to trying to synthesize eyelid motion in code.

## Priority B — useful for broader Director behaviour

### 6. Rattled
Not fear. Graham is slightly thrown and working hard to keep presenting.

### 7. Embarrassed
Useful after production failures, scoring mistakes and Announcer corrections.

### 8. Genuine anger, controlled
Key rule: not shouting horror-villain anger. Think presenter who has momentarily forgotten the audience can see him.

### 9. Long stare / no smile
A deliberate neutral stare to camera for rare broadcast incidents.

The existing neutral can temporarily serve this role.

### 10. Off-air exhausted
Tie subtly loosened, shoulders lower, smile gone. Best reserved for commercial-break incidents.

## Priority C — later polish

### 11. Applause acknowledgment
Small nod / modest smile / glance toward audience.

### 12. Scoreboard glance
Looks toward an implied studio monitor.

### 13. Podium / contestant glance
Useful for favourites, grudges and targeted humiliation.

### 14. Standing wider shot
Current material is primarily medium presenter framing. Eventually a full/wider studio shot will improve broadcast grammar.

### 15. Sitting / desk position
Optional. Only add if the final studio design actually uses a desk segment.

## Do not generate merely to fill the list

Future AI generation should be demand-driven. Generate a missing state only when:

1. The game is already playable.
2. Repetition is visibly hurting the illusion.
3. The exact missing performance is known.
4. Existing stills/camera edits cannot solve it cheaply.

The first serious Mildew proof of concept should **not** wait for Priority B or C assets.
