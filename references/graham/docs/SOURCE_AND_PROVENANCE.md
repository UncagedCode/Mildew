# Source & Provenance Notes

## Origin

The four source videos were supplied by the user in the Mildew design conversation after being generated as Graham concept tests.

This pack performs editorial extraction and cleanup:

- chooses the best frames;
- crops to 4:3 presentation;
- removes the accidental BBC-style corner bug from curated/reference derivatives;
- extracts short motion excerpts;
- extracts an audio performance reference;
- documents which generation is canonical.

## Real broadcaster branding

The BBC-style on-screen bug appeared as an unwanted generation artefact. It is not part of Mildew's fictional history and should not appear in production assets.

Do not add logos, idents or trade dress from real broadcasters simply to make the game look authentic. Create fictional broadcaster/production branding if any is eventually required.

## Commercial release

Before a commercial/public release, the project owner should confirm that the terms of the generation service used for the source concepts permit the intended use of those generated assets.

This pack does not make a legal determination about third-party service terms.

## Scientific/game content

These Graham assets are fictional presenter material and are separate from Mildew's factual image pipeline. Real animal anatomy, biological photographs and factual content still require the source/licence/approval metadata defined by the main Mildew specification.
